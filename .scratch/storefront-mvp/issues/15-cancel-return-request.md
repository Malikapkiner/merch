# 15: İptal ve iade talebi

**What to build:** Müşterinin Siparişi için iptal veya iade talebi oluşturması ve Admin'in talebi görüp Sipariş durumunu İptal veya İade yapması. Para iadesi elle yapılır.

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] Müşteri, uygun durumdaki Siparişi için gerekçesiyle talep oluşturur (Üye hesabından veya Misafir sorgulamasından)
- [ ] Admin talepleri listede görür ve talebi Sipariş detayında inceler
- [ ] Admin talebi sonuçlandırır: Sipariş İptal veya İade olur, not kaydedilir
- [ ] Teslim edilmemiş ve edilmiş Siparişler için geçerli talep türleri ayrıdır
- [ ] Kurallar modül arayüzü üzerinden test edilmiştir
